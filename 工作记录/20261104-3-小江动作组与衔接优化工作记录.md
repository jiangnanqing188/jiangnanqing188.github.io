## 完成内容

### 同风格素材

- 用内置 `image_gen.imagegen` 参考已确认的 `catgirl-field-notes.webp`，生成 4×4 动作原图和 2×2 状态原图。
- 保留银发、猫耳、琥珀眼睛、白尾和笔记本，统一墨绿外套、奶油白耳机与陶土橙细节。
- 20 帧：挥手 4、阅读/翻页 4、哈欠/伸展 4、迈步 4、犯困/坐下/睡眠/拎起各 1。
- `scripts/build-pet-atlas.cjs` 按固定网格机械分格、缩放到 320px 格子、合成 4×5 图集；不按坐姿包围盒单独放大，不重绘素材。
- 网页图集 1280×1600，约 551KB；静态首帧约 28KB。图集低优先级加载、成功解码才接入；加载失败仍有同风格静态图。
- 原图和最终提示词保存在 `规划/原型/assets/pet/field-notes/`；工具没有返回可核验的模型名或质量档位，不把指定模型当成实测事实。旧五张运行图不删除，但模板不再引用。

### 动作与打断

- 用单一序列通道替代多个 `act-*` 与睡眠 CSS 的竞争；清掉旧计时器/动画并递增 token，防止旧动作回写新姿势。
- 每个有限动作有起势/表演/恢复；挥手、翻笔记、伸展、迈步使用实际姿势，身体轻缓动作由 Web Animations API 处理。
- 睡眠为犯困 → 坐下 → 闭眼；唤醒先起身，随后执行最新动作意图。连续请求不堆队列。
- 行走有 180ms 起步、四拍循环和 260ms 收脚，位移曲线平滑起停。点击、菜单、拎起、后台、缩放等取消未完成位移。
- 拎起切到同风格悬垂姿势；停住超过 100ms 再放手不使用旧速度甩飞；取消/丢失捕获/进入后台不遗留拖动状态。
- 保留有界甩抛与落地；结束前写入真实接触点，再恢复与保存，避免停在上一帧的空中位置。
- 安静和减少动画偏好立即停止动态效果；保留静态睡姿、台词、键盘与位置功能。
- 保留自动停靠、下层控件点击让路、透明角穿透、存储偏好与手机纵向翻页优先。
