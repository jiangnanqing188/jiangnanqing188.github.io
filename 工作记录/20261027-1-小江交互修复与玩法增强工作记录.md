## 二、修复（提交 2654b95，tag `pet-fix-20261027`）

- `touch-action: none → pan-y`；`pointermove` 增加判断：触摸时以竖向为主则不启动拖动，交还浏览器翻页。
- 新增透明 `.pet-hit` 命中层，`clip-path` 采用按立绘 alpha 通道逐行采样生成的 32 点轮廓（站姿/拎起/睡姿三套）；图片改 `pointer-events:none`。焦点环改挂命中层，避免被 `clip-path` 裁掉。
- `z-index 25 → 9`，`position()` 增加 `topLimit()` 下限＝吸顶导航底边＋8px；删除"回到右下角"仅桌面可见的媒体查询，手机端也可用。
- 滚动计入活动（2s 节流），阅读期间不再进入待机。
- 五张立绘 640→400px、quality 84 重编码：**1101KB → 153KB（-86%）**；非首屏姿态 `loading="lazy"`、主图 `fetchpriority="high"`。
- `.pet-caption` 加 `white-space: nowrap`，手机端 40.7px → 20.3px 单行。

### 验证

- 竖滑宠物 → 页面滚动 **388px**，宠物未移动；横拖仍可移动（`is-landing`）。
- 三个角点 `elementFromPoint` 返回页面元素（`H2`/`DIV`），仅中心命中 `#blog-pet`。
- 拖到顶部：`petTop:91 ≥ headerBottom:83`，`brandBlocked:false`，`navBlocked:false`，`resetVisible:block`。
- 纯闲置 44s 入睡；持续滚动 30s 全程清醒，停手后按最后一次滚动 +45s 入睡（实测 36s 因页面已滚到底、末段无滚动事件）。
- `npm run build`、`npm run check:site`（63 页 / 2698 处本地引用）、`node scripts/check-reading.cjs` 全部通过。

## 三、玩法增强（提交 24dad3b，tag `pet-playful-20261027`）

参照 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（4300 star）的交互思路，**只借鉴行为设计，不引入其依赖或素材**；小江仍是两张过渡立绘＋CSS 变换，不是 Live2D/webm 动画链。

- **甩抛**：拖动时以 0.3 权重平滑跟踪速度（px/ms），松手速度 >0.35 即转抛物线飞行；重力 0.0032、边缘反弹衰减 0.62、地面摩擦 0.82，最迟 4s 强制收敛并落 `is-landing`。
- **漫游**：空闲 25s 后沿视口底部短距离（60–200px）走动，随机朝向；菜单新增"→ 走两步"可手动触发。
- **点击 Q 弹**：`pet-squish` 420ms 压扁回弹曲线。
- 三者均受安静模式与 `prefers-reduced-motion` 约束；键盘移动、拖动、打盹逻辑不变。

### 开发中修掉的两个真实缺陷

1. **TDZ**：`nap()` 调用 `stopWalk()`，但 `stopWalk`/`stopFlight` 在其后用 `const` 定义 → 首次打盹会抛 ReferenceError。已把两段定义前移。
2. **永远落地不了**：落地判定 `|vy|<0.06` 写在撞击瞬间，而此刻垂直速度最大，几乎永不成立 → 实测 1.6s 后仍 `is-flying`、位置未存储。改为判断**反弹后**速度（`bounce < .35 && |vx| < .12`）并加 4s 兜底。

### 验证

- 甩抛轨迹采样 14 帧：飞出 → 撞左墙 → 落地 → 摩擦减速 → 停稳 `[734,686]`，`is-flying` 正确清除，位置已写入 `jiangnan-blog-pet-v1`。
- 漫游：空闲后第 24s 观察到 `is-walking` 并位移（1233→1214）；菜单"走两步"点击后走 88px。
- 安静模式：点击不出 `is-squish`、甩出不出 `is-flying`（仅 `is-landing`）。
- 减少动画偏好：`pet-art` 的 `animationName` 为 `none`，无 Q 弹。
- 键盘方向键位移正常（1082→1052）；全程无控制台报错。
- `npm run build`、`check:site`、`check-reading` 重跑通过。
