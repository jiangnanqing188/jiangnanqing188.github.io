PROJECT 03

智慧药房双车系统

将导航、OCR、双车隔离、视觉联调和现场恢复串成一条可重复检查的机器人比赛工作流。

团队成果与项目进展

第二十八届中国机器人及人工智能大赛全国总决赛智慧药房三等奖；从单车基线推进到双车真实视觉联调

本人职责 ↓结果与证据 ↓相关记录 ↓

封面为 AI 概念插画，比赛证据见下方记录。

01 / PROBLEM

要解决的问题

两台车共用地图与 ROS Master，需要同时控制话题隔离、识别时序、导航稳定性和现场版本一致性。

02 / RESPONSIBILITY

我负责的部分

  • 初赛负责网络环境与实车测试，与另一支队伍的一名同学协作
  • 国赛独立负责代码编写与维护、网络配置和全部测试
  • 维护双车运行主流程，接入导航、OCR 与任务等待逻辑
  • 排查命名空间、视频流和识别话题串车，推进真实视觉联调
  • 建立 Git 基线、分层验证、跑圈记录与可回退的现场流程

协作边界

初赛阶段与另一支队伍的一名同学合作，对方负责代码，本人负责网络和测试；国赛阶段的代码、网络和测试均由本人独立完成。

03 / OUTCOME

结果与证据

第二十八届中国机器人及人工智能大赛全国总决赛智慧药房三等奖；从单车基线推进到双车真实视觉联调

2 篇项目记录；语法、契约、单车、双车和真实视觉证据分层标注；1 个公开工作流仓库
