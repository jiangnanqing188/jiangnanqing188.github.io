## 本地生成与检查

npm run build
npm run check:site
node scripts/check-reading.cjs
python3 -m http.server 4175 --bind 127.0.0.1 --directory public

## 猫娘与封面

猫娘名为“小江”，可点击打招呼、双击蹦跳、鼠标或触摸拖动、收起和叫回，支持键盘移动和减少动画偏好。点击名字旁的“⋯”打开小菜单，可让她蹦一下、打个盹、回到页面顶部、进入文章搜索，或切换安静陪伴。打盹会播放约 1.8 秒的姿态动画：站着犯困、低头点一下、屈腿坐下，最后闭眼抱着笔记本睡着；由两张过渡立绘与最终睡姿配合渐变和轻微位移实现，不再只把站姿倾斜或直接换图当作睡觉。睡着后只有轻微呼吸起伏和 zzz。45 秒无点击或键盘操作时也会进入同一打盹状态，清除原气泡，不主动弹消息；再次操作会以约 1 秒的反向姿态动画唤醒并恢复站姿；入睡中被打断时直接恢复站姿，开始拖动时立即停止过渡、切到拎起姿态。安静模式和减少动画偏好保留睡姿，但关闭入睡及呼吸动画。

拖动超过 6 像素时切换到专门的“被拎起”立绘：外套肩领提起、双脚悬空，鼠标对齐肩领抓取点；移动时有小幅倾斜，松手恢复站姿并轻轻回弹。拖动期间隐藏气泡和名字工具条，松手恢复工具条，不误触打招呼；安静模式与减少动画偏好关闭倾斜和回弹。现在使用站姿、拎起、犯困、屈腿、打盹五张 Q 版立绘配合整体变换，并非 Live2D 或独立衣料物理模拟。位置、收起状态和安静偏好保存在当前浏览器的 `jiangnan-blog-pet-v1`，保留此前的位置记录；台词为本地预设，不接入聊天服务。2026-10-02 完成的改名、拎起及入睡／醒来动画已于 2026-10-03 确认上线；Pages 发布提交为 `1fbf84d`。

五张新封面是 AI 概念插画，用于主题表达；页面已标注，不作为现场照片或工程证据。成长文章的真实团队合影保持原图，原封面与文章图片均保留。图像工具未返回可核验的模型和质量档位，不宣称锁定 Image 2.5 high。
