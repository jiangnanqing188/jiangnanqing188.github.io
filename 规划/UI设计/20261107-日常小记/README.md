## 生成依据

使用既有 CPA 直连入口，通过未修改的 imagegen skill CLI 请求 `gpt-image-2.6`，`quality=high`，桌面 1536×1024，手机状态板 1024×1536。现有 CLI 没有 xhigh 图像质量选项；不声称设置了该选项。仅请求的模型 ID 可核对，不额外声称供应方内部模型已独立认证。密钥仅内存传递，不存放在本目录。

## 还原约束

1. 共用现有主题字体、颜色和页头；内容是 HTML 文本和可操作控件，而不是设计图截图。
2. 所有文字小记公开阅读；仅作者本人 GitHub 登录核验后启用表单。
3. 默认空数据、明确空状态；服务未配置时不伪装发布可用。
4. 正文只当纯文本渲染；保留换行；会话不保存在本机持久存储中，草稿可只存本机。
5. 普通/深色、320px/390px/桌面、键盘焦点和减少动画偏好须实际检查。
6. 后端真实启用仍需一次性配置 GitHub App 和 Cloudflare；设计完成不代表这些账户操作已经执行。
