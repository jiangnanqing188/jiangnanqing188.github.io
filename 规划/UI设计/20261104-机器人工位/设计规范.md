# 整站 UI 设计与复刻规范

## 1. 目标与优先级

面对导师、实验室负责人、招聘方及技术同学：30 秒内理解“江南是谁、关注什么、做过什么、主要负责什么”，两分钟内找到代表项目、相关文章与证据。

视觉方向已经由用户确认：**第一版的纸色工程手记＋微缩机器人试验场，首页右侧嵌入未来视频。**小胖子是视频里的角色，不是新增网页桌宠，也不是用完整房间占满首页。

优先级：

1. `AGENTS.md`、当前文章与数据中的真实事实／隐私／职责。
2. 用户当前明确选择与本规范的功能边界。
3. `01`～`13` 设计图的布局、节奏、形状与氛围。
4. `00` 原始第一版只作风格参考；第二版“大房间”不在定稿包中。

生成图不是新的事实来源；不要把图里变形的字、示例正文、生成的证据或尺寸写进文章。

## 2. 设计语言

- **人和任务**：先快速了解一个做过真实机器人项目的学生，再决定深入阅读哪份项目档案。
- **领域词汇**：工位、场地、航点、工程手记、代码基线、实车检查、回退、项目档案。
- **色彩世界**：纸白、墨绿、鼠尾草绿、工程石墨、路锥橙、暖木色（仅插画）。
- **签名元素**：首页一个“小胖子调车”视频位；页间少量航点路线／编号／手绘下划线，形成统一的工程手记世界。
- **拒绝的默认套路**：满屏同尺寸圆角卡片→编辑式横栏和不等权重；整页大房间／大型人物→局部媒体位；假实时仪表／霓虹代码雨→可读正文与真实项目证据。
- 有趣主要发生在探索入口，阅读页主动收敛。不要给每行文字加手绘线或每个按钮加图标。

- 展示标题可用本机已有中文宋体／衬线栈；正文沿用项目已有 `--lab-read`；导航、表单与工具文字用 `--lab-sans`，日期与日志编号用 `--lab-mono`。不擅自安装字体或引入第三方字体请求。
- 桌面首页标题目标 52～64px；手机 32～38px。内页标题约 40～48px／手机 28～34px；正文约 20px／手机 17px。用实际长标题验证，不照图片尺寸硬套。
- 间距以 4px 为单位；主段落留白 40～64px，移动端 28～40px；分隔优先细线而非厚阴影。
- 大多数圆角 4～8px，媒体边界最多约 12px。纸纹只能极轻，不能降低字的清晰度。

### 3.1 首页

- 第一版的清楚左标题、身份、简介、两个主要入口与右侧微缩场地保持不变。
- 右侧改为**单个局部视频容器**，未来内容是小胖子在电脑前调车；人物和电脑是场地中的辅助故事，不把整个网页改成房间。
- 结果条分清团队结果与个人职责；项目数、文章数从当前数据动态得出。
- 代表项目睿抗权重最大，其后是药房与农业视觉；ISCC 通过项目档案可达，不制造新项目。
- 首屏之后展示精选复盘＋最近记录。保留现有四条 recent notes 且不与 featured 重复；设计图仅画了下沿示例，不意味着删掉两条记录。
- 不照抄原图虚构的“视觉分拣机械臂／自主导航与建图系统”项目。

- 仅用真实四项目；首项突出，其他横向档案行。手机单列，不保留狭窄两栏。
- 周期、团队、本人职责、协作边界、技术栈、结果和材料可见，不能只剩奖项。
- 睿抗：2026.06—08、3人、更换系统后的代码与适配本人独立完成；队友焊接；工程师IMU／现场硬件协助。
- 药房：3人；初赛与另一队同学协作，对方代码、本人网络与测试；国赛代码、网络与测试本人独立完成。结果三等奖。
- 农业：3人；前期主代码、硬编码路径、授粉YOLO模型，后期主要摄像头异常介入；结果一等奖，但不包装硬编码为核心导航能力，不生成mAP／FPS等指标。
- ISCC：3人；本人通信加密与HMI按钮，两名队友PLC；HMI任务本身就是按钮，不擅自扩展为完整HMI开发。
- 睿抗时间线：8月9日移除第一代“致命障碍”黄线；8月17日开发第二代软代价，不是恢复旧代码；8月19日放弃黄线，8月20日纯点位完成正式赛94分。
- 材料状态区只写真实已公开入口／未整体公开状态，不生造日志、照片、下载按钮。

### 3.3 文章列表与阅读

- 搜索现有全文索引，分类按真实集合；图里的“按发布时间”仅静态说明，不要求新增排序功能。
- 无结果是替代状态，不能与正常列表同时呈现；空态可重置关键词和筛选，带可感知结果计数。
- 保留“成长经历→工程取舍→视觉深入”的睿抗阅读路线，不产生虚假文章。
- 阅读页标题、摘要和所属项目先于长正文，目录桌面粘性、手机可折叠；代码复制、表格独立横向滚动和懒加载评论保留。
- **图里的正文／段落标题是排版示例，不是文章修订授权。**尤其不能用图中的简写替换原作者的失败、Sol吐槽、求助、职责和验证边界。
- 点5绕行与点9车体雷达／footprint问题不可因图稿摘要被合并；“没插电”原事涉及枪与云台，不得改写为整车电池没电。
- 阅读页无视频自动播放、无持续人物动画、无自定义鼠标尾迹；不让宠物挡目录和正文。

- 四奖项按源码正式全名展示且均标团队：睿抗一等奖、农业一等奖、药房三等奖、ISCC三等奖；不公开证书编号与其他人姓名。

## 4. 视频区域：这次只预留

- 位置：首页右侧主视觉；手机放简介与主入口之后，不独占首屏。
- 主题：小胖子用电脑调车，微缩试验场为主体。小胖子不是用户真实肖像，也不是新的悬浮角色。
- 与文章的联系：定位问题、检查电源与连接、验证方案、保留回退。属于主题演绎，不声称比赛现场复现。
- 本次不制作、下载、转换、配音或上传视频，也不接入视频服务。
- 图中播放图标表示**未来有视频时的状态**。实现时若仍没有视频，只展示静态主题封面，不出现可点击但无作用的播放／音量／全屏按钮，不用setTimeout假装加载成功。
- 未来有本地视频素材后，建议实际 `<video controls playsinline preload="none" poster="…">`，默认不自动出声；遵循减少动态偏好，按需载入，保留清楚可达的播放暂停。不新增跟踪、第三方播放器或外部存储。
- 固定媒体比例避免布局跳动；不把整幅网页截图塞入video/poster，文字、导航和按钮仍是原生网页内容。
- 用“原创主题短片／非比赛实录”一类标注区分视频、概念插画和项目原始证据；尚无文件时不能宣称短片已制作完成。

## 5. 手机、键盘与深色

- 验收宽度建议320、390、768、1280、1440；这些是待实施测试，不是当前已通过结果。
- 手机页头两行：品牌＋搜索／主题；下一行四个导航，不新增压住正文的固定底栏。
- 长标题与文件名可换行；邮箱与代码有恰当断行／独立滚动；整个页面不能横向溢出。
- 详情目录、阅读目录和关于索引折叠；项目详情时间线竖排。
- 分类按钮自然换行；标签不靠超大随机词云，资源表在手机变逐项条目。
- 控件触点目标至少44 CSS px，键盘可达；当前页面不能只靠颜色表示；图中辅助页错误高亮“首页”的装饰不照抄。
- 保留跳到正文、focus-visible、减少动态偏好、替代文本与真实按钮语义；不把文字烘焙到整页PNG。
- 深色图只给出首页和阅读的主题样例，全部页通过相同语义令牌继承。照片／概念插画不反色、不统一压到看不清；无图稿不等于删除其他页深色支持。
- 沿用既有小江的停靠、点击穿透、拖动、收起、菜单、手机滑动与打印隐藏。图里的普通猫／猫娘属于示意，不能替换已有素材或回退交互。

1. 初始关于稿把药房写成一等奖，已用图像编辑修正，交付只保留 `06-about.png` 修正版。
2. 文章列表与手机图的个别封面错配（如四套视觉用了农业画面），必须用文章现有封面。不能据此重新分类或替换内容。
3. 文章列表第五项示例日期／类别有误：实际《国三之后…工作流》源日期 `2026-07-30 22:45:00`、类别“工程复盘”；不是图里的8月19日“成长记录”。
4. 项目列表图里农业周期使用了占位语，正式值是“智慧农业备赛阶段”；ISCC周期是“线上比赛与限时录制阶段”，不能拿年份当全部周期。
5. 部分图中字形缺字、错字、标点及年份／文章数变形；真实标题、统计与邮箱从源码读取。提示词不能保证图中文字逐字正确。
6. 分类／标签两页图中导航可能装饰性高亮首页，正式辅助页不高亮首页；来源集合优先于示意标签。
7. 原始第一版中的假机械臂项目、第二版大房间、任意蓝图尺寸／遥测数字均不属于实施目标。
8. 画面只有概念插画，绝不当作真实机器人结构、场地、证据或硬件接口图。
9. 现有Hexo在本机日期解析与缓存可能表现为路径偏移；复刻不得顺手改文章日期、timezone或永久链接。若发现既有问题，单列报告，不混进UI任务。
