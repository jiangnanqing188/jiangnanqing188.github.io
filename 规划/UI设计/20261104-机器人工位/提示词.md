# 生图提示词规格集

这是本轮已使用设计要求的**可复用归纳版**，不是逐字请求日志。所有图均经内置 `image_gen.imagegen` 生成或编辑，不使用收费CLI；底层具体型号未由工具返回。原始输出文件名与交付文件在 `manifest.json` 对应。

## 共同基础提示词

```text
UI-MOCKUP. Design a real Chinese personal robotics blog interface titled 江南的碎碎念 / ROBOTICS FIELD NOTES. Match the user-selected FIRST reference: open ivory engineering notebook, forest-green ink, pale sage, restrained burnt-orange waypoint annotations, beautiful expressive Chinese editorial headings, fine rules, generous whitespace. No generic equal bento cards, neon cyberpunk, browser frame, laptop mockup or full room wallpaper. Use authentic project content and clear evidence boundaries. Each screenshot is a static design, not implemented UI. Typography and controls must remain buildable as semantic HTML, not a page-sized bitmap.
```

颜色意向：ivory `#f5f3eb` / forest `#183f35` / sage `#dfe8da` / restrained terracotta `#c66d3d`。实际网页色值需按规范进行可读性验证。

## 后续生成素材时的约束

使用独立图片／分层资产提示词，不从整页稿裁按钮和正文当生产素材；只在用户授权制作视频后安排视频。人物属于卡通主题角色，不冒充本人真实肖像；所有概念插画标注，不当作比赛原始材料。
