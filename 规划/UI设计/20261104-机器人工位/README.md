## 设计性质与限制

- 图片由内置 `image_gen.imagegen` 生成；该工具没有模型选择参数，返回结果也没有模型标识，因此**不能独立确认底层是否为用户最初指定的 Image 2.5**。未更改任何用户模型设置，也未调用收费 CLI。
- 全部是静态图片，不是浏览器实拍；“390”是移动端设计目标，不是已实现页面的真实 CSS 像素测量。
- 图中的文字、封面、局部图示仅用于排版表达。已修正关于页药房奖项的明显错误，但其他生图细节仍须按源码纠偏，详见规范。
- 播放按钮、代码复制、筛选、目录等在图中不可操作。**目前没有视频文件**，不能据此报告播放器已实现。
- 旧 `规划/原型/` 保持历史快照身份；本目录没有覆盖旧原型或修改正式主题。
