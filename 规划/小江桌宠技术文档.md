## 1. 当前实现与风格

小江是博客里的独立伙伴，不是首页“小胖子调车”的人物分身。用户确认的工程手记风保留银发、猫耳、琥珀眼睛、白尾和笔记本，改为墨绿外套、奶油白内搭、耳机与陶土橙细节。动作源图由内置图像工具参考已确认立绘生成；不引入他人的角色图或动作素材。

当前运行方式是 **36 个离散姿势 + 原生 JavaScript 调度 + Web Animations API 身体缓冲 + CSS 待机呼吸**。没有 Live2D、骨骼、视频循环、聊天接口，也没有新增前端依赖。挥手、翻页、伸懒腰和行走已经有实际姿势变化；点头、张望、受惊等仍以身体小幅变换为主。

## 2. 图集与锚点

从 0 开始逐行编号：

| 帧 | 姿势 |
| --- | --- |
| 0–3 | 挥手起始、抬掌、回摆、闭眼笑 |
| 4–7 | 抬起笔记本、阅读、翻页、抬头 |
| 8–11 | 犯困、打哈欠、伸展开、放松手臂 |
| 12–15 | 原来的四个迈步关键姿势 |
| 16 | 站立犯困 |
| 17 | 坐下、眼睛未完全闭合 |
| 18 | 抱笔记本睡着 |
| 19 | 拎起衣领、手脚悬垂 |
| 20 | 真正的自然垂手待机（取代原先始终抬手的第 0 帧） |
| 21–22 | 手从腰侧抬到胸前/反向收手 |
| 23–24 | 双手抱合拢的笔记本、半开笔记本 |
| 25–27 | 手接近嘴边、半抬臂伸展、半放下手臂 |
| 28–30 | 浅屈膝、半蹲、低蹲 |
| 31 | 自然站姿眨眼 |
| 32–35 | 四个迈步中间姿势，与 12–15 交替构成八相位 |

姿势使用固定方格，不按各帧外接矩形单独放大，防止坐姿的头突然变大、走路时身高抽动。脚底大致共用格子底部锚点；生成图之间仍有轻微手绘差异，不声称达到骨骼动画的像素连续性。

`paintPose()` 按帧号选图：0–19 使用 `actions.webp`、`background-size: 400% 500%`；20–35 使用 `transitions.webp`、`400% 400%`，后者先减去 20 再计算位置。原图集编号与采样方式不变，不把整张图集放大成另一种行数。

默认底图与第 20 帧来自同一格裁切，图集加载完成时保持自然垂手姿势。所有姿势随 `.pet-visual` 的独立 `scale` 属性统一镜像；身体缓冲使用 `transform`，不会在换动作时把朝向覆盖掉。图集中人物默认略向左，`.face-right` 表示向右镜像；命中轮廓同时镜像。

## 3. 单一动作通道与衔接

`run()` 负责有限动作，步态由同一动作通道下的 RAF 按距离驱动。每一步写成 `[frame, milliseconds, phase]`，`data-motion`、`data-pose`、`data-phase` 是可读的当前状态，不暴露控制接口。

- `cancelMotion()` 先取消当前定时器与身体动画，并递增 token，使旧序列不能回来改姿势。
- 新动作从当前计算后的身体变换接续，再回到中性姿势，不叠加多个 `act-*` CSS 动画。
- 手势帧只用 32ms 短交叠，恢复中性姿势约 40ms；当前层保持不透明，仅让上一层退去，避免共有轮廓整体发白。坐下/起身和步态不交叠，避免两个头或四条腿的双影。
- 有限序列按绝对累计截止时间推进，避免每次回调延迟不断拉长动作。
- 阅读、抬手、伸展或走动被新请求打断时，先经过合书/收手/落脚的短恢复，再执行新动作。恢复期间只保存最新请求，不反复重启；跳跃与放下保持及时响应。
- 所有有限动作有恢复阶段。起步和收脚也属于动作通道；自动待机动作只在角色真正空闲、菜单关闭、标签页可见时触发。
- 睡眠中的新请求先经过起身。等待期间只保存**最新一个**动作意图，不把连续点击积成队列。
- 拖动、隐藏、后台、缩放和偏好变化会取消其不再适用的定时器、移动帧或指针捕获。

### 主要序列

| 行为 | 顺序与边界 |
| --- | --- |
| 打招呼 | 自然垂手 → 半抬手 → 挥手 → 两段收手 → 垂手；约 1.31 秒 |
| 翻笔记 | 抱本 → 半打开 → 阅读/翻页 → 半合 → 合本 → 垂手；约 2.41 秒 |
| 伸懒腰 | 手到嘴边 → 哈欠 → 半抬臂 → 伸展 → 两段放下 → 垂手；约 1.78 秒 |
| 蹦跳 | 160ms 蓄力 → 360ms 腾空 → 180ms 着地 → 260ms 恢复 |
| 打盹 | 哈欠 → 犯困 → 抱本 → 浅屈膝 → 半蹲 → 低蹲 → 坐下 → 闭眼；约 1.53 秒 |
| 唤醒 | 睁眼 → 低蹲 → 半蹲 → 浅屈膝 → 抱本 → 垂手；完整起身约 800ms，随后才回应；刚犯困时较短 |
| 行走 | 220ms 起步 → 距离同步的八相位步态 → 370ms 收脚；位移速度由平滑起停曲线控制 |
| 落地 | 身体轻压、回弹、站稳；约 460ms |

菜单新增「翻翻笔记」「伸个懒腰」。原有跳跃、打盹、走动、鼓励、复位、顶部、文章搜索和安静模式保留。点击/键盘打招呼、双击跳跃、连点反馈仍由原有事件语义触发。

## 4. 走动、拖拽与甩抛

### 走动

首次自动尝试约 27 秒，之后约 25–45 秒检查一次；一次选择附近 60–200px 的目标。自动走动和其他动作不能争用同一通道，睡着时不会被漫游定时器强行拉起来。

步态使用 `[12,32,13,33,14,34,15,35]`，一个步态循环对应约 `角色宽度 × 0.24` 的位移，而非独立循环定时器；身体起伏与步态相位一致。起步先抱好本子，结束或被打断时选落脚姿势，再抱本、垂手；还没迈步就被打断不会多踏一步。

位移进度采用 `t²(3−2t)`，起点和终点速度均为零；不能把每一格迈步当作瞬移。沿用 `dockBand` 的活动边界，车道不足时只张望。菜单打开、点击打招呼、拖动等会取消未完成的位移帧；旧 RAF 不得在对话或新摆位后继续移动她。

### 拖拽

- 仅主指针左键能发起；角色按钮捕获该指针。
- 距离小于 6px 不算拖动。手机纵向滑动保留给原生翻页，横向移动才进入拎起。
- 开始拎起时取消原动作，切到第 19 帧；按朝向取衣领锚点，角色悬在指针下方。摆角约 ±8°，安静或减少动画时不摆动。
- 放手前最近移动样本超过 100ms，视为停住后放下，不使用旧速度制造延迟甩飞。
- `pointercancel`、捕获丢失或后台中断必须释放拖动状态；已产生的手动摆位仍保存。

### 甩抛

沿用原有有界物理：平滑速度、速度上限、边缘反弹、重力与地面摩擦。单步 `dt ≤ 32ms`，重力为 `.0032 px/ms²`，地面反弹系数 `.55`、摩擦 `.82`。释放速度超过 `.35 px/ms` 才甩出，安静和减少动画时禁用。

判定停稳用的是**反弹后的速度**而不是撞地瞬间速度，避免越弹越停不下来。着地结束前先写入最终接触点，再结束飞行和保存位置，避免恢复站姿时留在上一帧的空中位置。隐藏、后台和缩放会取消飞行，不让后台积累物理步长。

## 5. 停靠与点击让路

保留本轮 UI 重设计后的安全摆位逻辑：手机默认留在 `.pet-workstation` 纸边工位，真实占据文流空间；桌面只有在版心侧边足够宽、滚动采样覆盖评分为零时才自动悬浮，没有安全边距就回到工位，不再选择“最少挡字”的角落。无 JavaScript 时也保留文流工位。

用户主动拖动、方向键摆放或选择「走两步」可以离开工位；手动位置优先，菜单复位恢复自动选择。文流状态不会自动漫游，也不为默认摆位制造一条用户存储。主动放到文字上仍可能遮挡，不宣称所有位置都零遮挡。

`.pet-hit` 是唯一接收指针的角色轮廓，图层、透明角和外层容器本身不抢指针。站立、低蹲/坐下/睡眠和拎起使用相应轮廓，随朝向镜像。

`underPointer()` 临时关掉命中层，查询其下的页面元素，再立即还原。下方若是链接、按钮、输入、选择、标签或折叠控件，`yieldTarget()` 把点击让回页面，避免宠物成为读者无法点开的挡板。键盘打招呼不走鼠标像素让路。

## 6. 睡眠、安静模式与可访问性

- 页面指针、键盘和阅读滚动会更新约 45 秒的闲置计时。到时只有空闲才打盹，不能打断正在交互或走动的角色。
- 空闲小动作首次约 18 秒，之后约 16–30 秒；从翻笔记、伸懒腰、哈欠、张望中选择，不连续抽到上一次的空闲动作。
- 安静模式保留可点击状态、台词和静态睡姿，不播放手势、迈步、跳跃、甩抛或睡醒动画。开启时立即取消正在播放的动作。
- `prefers-reduced-motion` 同样取消这些动态效果，且监听运行中的偏好变化；静态姿势仍可切换。
- 标签页进入后台后取消动作和移动；返回后重新安排闲置计时。离开超过 90 秒时保留有界的回来问候，执行前再次检查可见性与安静偏好。
- 角色是原生 `<button>`，有标签、说明与可见键盘焦点。Enter/空格打招呼，方向键移动，Shift 加速，Escape 关闭气泡/菜单。
- 气泡使用 `role="status"`；视觉图层是装饰，角色身份与操作说明由按钮和 `pet-help` 提供。
- `@media print` 完全隐藏小江。不会把她印在文章或 PDF 上。

存储仍为 `jiangnan-blog-pet-v1`，结构版本 `v: 2`。`auto:false` 的手动位置优先；隐藏与安静偏好保留。不读取账号、模型余额、会话消息或远程桌宠数据。

## 7. 修改与验证

新增动作优先复用当前图集：在 `ACTIONS` 定义姿势、时长与必要的身体缓冲，再接入实际事件。不重新引入 `act-*` 动画抢同一元素，也不要把旧风格睡姿混回新版图集。

重新分格需要本机 ImageMagick，原图保存在设计目录中：

```bash
node scripts/build-pet-atlas.cjs
```

构建应使用站点约定时区，避免主机默认时区让日期永久链接偏移：

```bash
node --check themes/notebook/source/js/pet.js
TZ=Asia/Shanghai npm run clean
TZ=Asia/Shanghai npm run build
npm run check:site
node scripts/check-reading.cjs
node scripts/check-pet.cjs
```

浏览器回归使用已有 Playwright 与 Chrome，未新增 npm 依赖。非项目本地安装时用 `NODE_PATH` 指向已有运行库；`CHROME_PATH` 指定浏览器，`PET_QA_DIR` 指定截图目录。脚本只监听临时 loopback 端口，阻断外部请求，结束时关闭浏览器与服务；Hexo 导入 `scripts/` 不会执行测试或重建图集。

`check-pet.cjs` 当前有 35 组检查，覆盖实际浏览器内的图集与透明度、动作序列、打断、睡醒意图、迈步/收脚、甩落、捕获取消、持久化、点击让路、安静/减少动画、素材失败与无 JS 底图、后台与打印；桌面 1440×1000、手机模拟 390×844 下检查首页、项目页和真实存在的文章页，并截取页面图。

长时间状态验证使用浏览器可控时钟；另外用真实时间播放与录制核对可见帧和身体缓冲。可控时钟的逻辑检查不替代真实播放检查。手机触摸使用 Chrome 设备与原生触摸事件模拟，**不是实体手机验收**。

## 8. 已知边界与回退

- 36 帧是离散姿势，身体变换与短交叠只改善过渡；不是连续骨骼动画，也没有口型或任意角度转身。
- 默认文流工位已检查不覆盖正文；手动摆位仍需用户自行选择空处。改为无 `main` 的全宽布局时需要重新评估。
- 动态内容改变之后不会自动重算全页停靠；菜单「回到不挡字的位置」仍是手动重算入口。
- 当前只在 Chromium 桌面与设备模拟中验证，尚未验证真实手机、Safari 和 Firefox。
- 动态图集共约 991KiB，低优先级加载并保留约 28KiB 静态图；本轮增加约 441KiB。继续扩帧前应先评估收益与传输体积。
- 本轮不修改站点其他页面、首页视频或外部仓库；源码 `1d879cc` 于 2026-11-07 推送并按用户要求部署，Pages 发布提交 `8dcf473`。旧五张立绘未删除，可配合旧版模板、JS、CSS 从 Git 一并恢复；只换回某一张旧立绘会导致混风格。

本轮回退基线为 `eacc1b4`。按本轮独立提交反向恢复动作代码、两张图集映射与默认底图即可，不回滚之后的其他 UI/内容提交。新增原图与构建脚本足以重新生成运行素材。
