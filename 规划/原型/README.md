# 暗色多页博客 UI 原型

本目录用于审阅 UI，未接入 Hexo 正式页面。首页、项目、文章和关于保留独立页面，项目详情与文章全文可以继续点击阅读。

## 预览入口

- 首页：`首页设计初版.html`
- 项目列表：`项目.html`；四份详情位于 `项目/`。
- 文章列表：`文章.html`；八篇全文位于 `文章/`。
- 关于：`关于.html`
- 封面对比：`封面对比.html`；五种主题并排展示原图与定稿。

从仓库根目录启动静态预览：

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

浏览器访问 `http://localhost:4174/规划/原型/文章.html`。图片相对引用现有 `source/img/`，请保留目录关系。

## 修改与生成

- `assets/style.css`：所有原型页面的公共样式。
- `assets/site.js`：文章搜索、分类筛选、主题关键词入口与目录交互。
- `assets/pet.html`、`pet.css`、`pet.js`：原创 Q 版猫娘小白的透明立绘、轻微动画和交互；生成器在全部预览页中引用。
- `build.cjs`：页面模板与生成入口。读取当前项目、奖项数据和 Markdown 文章；只写本目录的 HTML。

更新原型模板或文章内容后，在仓库根目录运行：

```bash
node 规划/原型/build.cjs
```

HTML 是设计审阅快照，站点内容仍以 `source/` 为准。初版仅引用现有图片。2026-09-30 封面迭代新增五张 AI 概念插画，保存在 `assets/covers/`，详见该目录说明；五张均已确认并用于原型页面。没有新增依赖或修改正式站点渲染代码，也没有推送或部署。视觉确认后，再把样式与布局适配到正式页面。

## 网页宠物小白

小白只出现在原型页面中。点击打招呼，拖动改变位置；收起后点击“小白”按钮叫回。聚焦角色后可用方向键移动，Enter／空格打招呼，Escape 关闭气泡。

位置和收起状态只保存在当前浏览器的 `jiangnan-blog-pet-v1` 本地存储中；存储不可用时仍可交互，但不记忆。台词是按页面类型提供的本地预设，没有网络聊天请求。手机尺寸较小，遵循浏览器的“减少动画”偏好。立绘为 AI 生成的原创 Q 版猫娘，采用约两头半身的大头短身比例，银白头发、琥珀眼睛、深灰外套与白色猫尾；资源及说明在 `assets/pet/`。目前为单张立绘的轻微摆动和点击反馈，并非 Live2D 骨骼动画。
